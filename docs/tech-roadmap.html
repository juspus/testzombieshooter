Under the Floorboards

The game runs and all 520 tests pass. The risk is the next month. src doubled in two weeks, from 13,900 lines to 28,400, and every new mode adds branches to the same four big files. This roadmap makes the next feature cheaper and the frame lighter on phones. It is not a rewrite. The only change a player should notice is a smoother frame.

  • 0CI runs. 520 tests exist, and nothing runs them on a pull request.
  • 117meshes per zombie. Each one is a draw call when it's on screen.
  • 2.05msper frame for mobile auto-shoot targeting with 25 zombies in front.
  • 90checks of which mode is on, spread across 15 files.

Not now, and why

  • Rapier physicsStill deferred from TODO.md. There's no collision problem to solve today, and it adds a large WebAssembly download.
  • An ECS library (bitECS, miniplex)The zombie system module gets most of the benefit with plain arrays and no new dependency.
  • A different engineDecided against on 15 June. Nothing here changes that call.
  • Skinned or GLTF zombie modelsThat's a new art pipeline. The merge card keeps the lo-fi box look you picked.
  • Switching maps without a reloadACTIVE_MAP is fixed at page load in six files. Fix it when a feature needs it, for example a map pick in the versus lobby.
  • Quality tiersYou skipped them on the main roadmap, and the frame governor already covers the GPU side.
  • A server for 3–4 playersStill the open P2P vs server question from the main roadmap. The protocol card makes either path easier.

How this was measured

  • npx vitest run: 51 files, 520 tests, 14.6 s. vite build: 5.6 s.
  • Scene counts: Playwright with SwiftShader on /?wave=1 and /?wave=8, after startGame() and skipIntermission(), reading gl.info over one frame and walking the scene.
  • Raycast timings: the same page, 100 runs of Player.jsx's five auto-shoot rays against every zombie, against two boxes per zombie, and 12 pellets per shotgun shot. This is a desktop CPU in a cloud container. A phone CPU is several times slower.
  • Line counts: wc -l on src without tests, on 05aaef9 (26 Oct) and today.
  • Mode checks: grep for runMode, mpRole, director.active, versus.active and dirDefending comparisons.
