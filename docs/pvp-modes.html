Rules for every versus mode

  • Same seed for both. Wherever zombies, drops or box rolls are random, both players get the same rng.js stream.
  • Cosmetic progression only. No perk, loadout or level unlock carries into versus. The Supporter Pack stays skins only.
  • Auto-shoot off when players aim at each other. Aim assist becomes a slowdown near the target. Against zombies only, it can stay on.
  • The host has an edge. The host decides drops and hits with zero lag. Fine for friends; say it in the lobby, and fix it only if versus goes public.
  • No solo pauses or slow-mo. Last-kill slow-mo is off, and a pause pauses both players or nobody.
